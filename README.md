# 🍳 Breakfast App

A modern and visually appealing **Breakfast App UI** designed to provide users with a simple way to explore breakfast food, browse categories, and discover recommended and popular meals.

## 📱 App Overview

The Breakfast App provides a clean food-browsing interface with both **vertical and horizontal scrolling**. Users can explore different breakfast categories, view recommended meals, and browse popular breakfast items.

## ✨ Features

- 🔍 **Search Bar**
  - Search for breakfast items such as pancakes.
  - Includes a filter/settings icon for additional options.

- 🍽️ **Breakfast Categories**
  - Browse different food categories horizontally.
  - Example categories:
    - Salad
    - Cake
    - Pie
    - More categories

- ⭐ **Recommendation for Diet**
  - Displays recommended breakfast items in horizontally scrollable cards.
  - Each card contains:
    - Food image
    - Food name
    - Difficulty level
    - Preparation time
    - Calories
    - View button

- 🔥 **Popular Breakfast**
  - Displays popular food items in a vertically scrollable list.
  - Each item includes:
    - Food image
    - Food name
    - Difficulty level
    - Preparation time
    - Calories
    - Navigation button

- ↔️ **Horizontal Scrolling**
  - Categories can be scrolled horizontally.
  - Recommended food cards can be scrolled horizontally.

- ↕️ **Vertical Scrolling**
  - The complete breakfast screen can be scrolled vertically to explore more content.
